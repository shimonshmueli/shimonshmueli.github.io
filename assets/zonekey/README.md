# ZoneKey Pro assets

Drop the following files in this directory and they'll appear automatically on the site:

- `icon.png` — the app icon (recommended: 256×256 or larger, square)
- `screenshot-1.png` through `screenshot-5.png` — gallery screenshots (recommended aspect ratio: 16:10)

If a file is missing, the site falls back to a placeholder so the layout still looks intact.

To add or remove screenshots beyond 5, edit the `<figure class="shot">` elements inside the `#zonekey` section in `index.html`.
